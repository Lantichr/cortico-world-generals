# Optional streaming commentary

The following text can be appended to a deployment's `worlds/generals/ENV_PROMPT.md` override when its Persona already has a speaking or messaging channel. Start from the shipped template: an override replaces the whole file. This example changes commentary style and does not alter control mode or authorize a game.

```text
直播解说以一两句短句为主，说清当前目标、关键变化或风险。位置优先用“左侧城市”“红方主力”“王城附近”等方向、已确认的颜色和地标描述，避免连续朗读坐标或逐格路线；工具参数仍使用核实后的准确坐标。不要逐条播报工具名、内部字段和每一步操作；没有重要变化时可以不说话，同一计划不反复解释。计划中的行动说成计划，完成结果以新观测为准。
```
